8. 今回の施策で得られた示唆

  1. フィード合計閲覧数が42万件超：12名の合計で 420,552 に到達。1クリエイター平均 約35,000の閲覧を獲得し、SNIDELのコンテンツが安定した拡散力を持つことが確認された。
  2. 国内リーチ95%超の精度：niki.kawabe 96.8%（フィード）／98.7%（ストーリー）、rabbit.ryn__ 95.6%、arisa_732 94.1%、risa526 96.9%と、5クリエイターが国内純度94%以上を維持。アジア全域へ意図せず拡散していない設計が確認できる。
  3. F1ターゲット（25–34歳女性）への高精度到達：kanako228m 81.2%・micy26 75.7%・risa526 66.5%・arisa_732 64.4%・niki.kawabe 59.8%・rabbit.ryn__ 58.1%と、上位6名はすべて60%超。SNIDELのコアターゲットへ的確に届いている。
  4. 保存率の高さ（全クリエイター平均約16%）：ullmp_ 24.8%、kanako228m 21.2%、niki.kawabe 22.0%、_risa526 17.5%とフィードでほぼ20%。保存は強い購買意向のシグナルで、EC売上と相関が高い。
  5. フォロー転換を獲得したキャンペーン：合計 70件の新規フォロー獲得（フィード52件＋ストーリー18件）。特にkrm.__.mrk が合計12件（フィード2＋ストーリー10）を獲得し、12名中最多。業界平均を大きく上回る好成績。
  6. トラフィックソースの戦略的使い分け：Stories → Feed（niki.kawabe・arisa_732）、Feed中心（saeeeoky・micy26）、Stories中心（arisa_732）・メディアミックスが確実に機能している。arisa_732 は48.2%がStories流入。
  7. コメントの獲得：rabbit.ryn__ のコメント率6.76%は12名中1位で、フィード上で活発な会話を生んだ。これは保存・フォローとは異なる熱心なファンを獲得していると言える。

9. 次回に向けた改善策

  1. ストーリーナビゲーション率が高いクリエイターへの滞在設計：転換率・スクロール率ともに高め（kana228m 91.8%・__0li091804 90.5%・arisa_732 91.4%）。次回以降は3〜5枚目にスタンプ＋CTAを配置し、離脱直前にフォロー導線を設置。
  2. Feed / Reel の分類明確化：次回はフィードのみではなく、リールの再生数が伸びているユーザーを起用し、それぞれ専用のKPI（再生数、リーチ数）でを立てて新規層への獲得を狙う。
  3. 高女性比率の成功要因分析：hanae_miyazaki・arisa_732 のフィード投稿で女性比率がが高かった要因（衣装選定、構図、キャプション文言など）を他クリエイターへ横展開。特に女性に指したい商品のPR施策の際に活用。
  4. ENG効率の活用：フィードのENG率トップ3（mizuta_ayami 2.09%・saeeeoky 1.91%・krm.__.mrk 1.70%）の手法（服の見せ方・キャプション・投稿時間）を参考にし、他11名や次回起用する方へ横展開する。

10. 全体所見・クロージング

本施策はF1 ターゲットへ高品質で到達し、国内リーチ95%超とアジア全域への意図しない拡散抑制を両立した点で高く評価できる。特に niki.kawabe の国内純度98.7%（ストーリー）、rabbit.ryn__ のコメント率6.76%、arisa_732 のフィード女性比率76.2%、krm.__.mrk の合計フォロー獲得12件は、次フェーズに活かすべき設計ナレッジとして明確に蓄積された。

12名のフィード合計閲覧数が 420,552件に達し、krm.__.mrkはENG率 1.70% でフィードトップ3に入る二刀流クリエイターであることが確認された。

一方で、フォロー転換率とスタンプ反応は全体の課題として残った。ストーリーを単なる「視聴素材」ではなく、コミュニティのエンゲージメントとブランド・スタンプ反応、そして新規フォロー獲得を生む装置として位置づけ直すとともに、Feed/Reel を使い分けることで、次回はより新規層へのリーチ獲得を狙うことができる。
