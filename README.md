# レポート公開の手順

HTMLレポートを `https://goodvibesagency.tokyo/reports/` で公開するための場所です。
**Gitの知識は不要です。ファイルをドラッグ&ドロップするだけで公開されます。**

## 手順（3ステップ）

### 1. ファイル名を決める

公開したいHTMLファイル（またはzip）の**ファイル名がそのままURLになります。**

```
202609-snidel-ig-pr-report.zip
        ↓
https://goodvibesagency.tokyo/reports/202609-snidel-ig-pr-report/
```

ファイル名は `年月-ブランド名-内容` の形で、**半角英小文字・数字・ハイフン**だけを使ってください。
（日本語のままでも公開はされますが、URLが読みにくくなります）

### 2. アップロードする

1. このページ上部の緑の **Add file** ボタン → **Upload files** をクリック
2. ファイルを画面にドラッグ&ドロップ
3. 下の緑の **Commit changes** ボタンをクリック

zipのままでもHTML単体でもOKです。フォルダを作る必要はありません。

### 3. 待つ

**2〜3分**で自動的に公開されます。以下から確認できます。

https://goodvibesagency.tokyo/reports/

公開済みレポートの一覧が自動で表示されます。

## よくある質問

**Q. 内容を修正したい**
同じファイル名でもう一度アップロードすれば上書きされます。

**Q. アップロードしたのに一覧に出てこない**
3分待っても出ない場合は、上部の **Actions** タブを開いて赤い×が付いていないか確認してください。×が付いていたら徹さんに連絡を。

**Q. 間違えて消してしまった**
GitHubは全ての変更履歴を保存しているので復元できます。徹さんに連絡してください。

## 注意

- ここに置いたページは **URLを知っていれば誰でも見られます**
- 未公開情報・個人情報・単価などが含まれていないか、アップロード前に必ず確認してください
- `.github` フォルダは自動化の設定です。触らないでください
